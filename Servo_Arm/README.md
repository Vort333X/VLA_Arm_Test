# 下位机软件说明

STM32F103C8T6 裸机运行。J1～J5 驱动机械关节，J6 控制夹爪，J7 为备用。模型坐标与舵机角的换算见[网页坐标说明](../WebHost/README.md#关节角与串口角)。

## 软件架构

| 模块 | 职责 |
|---|---|
| [main.c](Core/Src/main.c) | 初始化外设；每 20 ms 调用 `Arm_Update()`，每轮主循环调用 `Arm_ProtocolPoll()` |
| [arm.c](Application/Src/arm.c) | 管理 `servo_j1`～`servo_j7` 实例；逐路读取 ADC 并更新控制。ADC 读取失败时跳过本周期该路输出更新 |
| [servo.c](Application/Src/servo.c) | ADC 角度换算与滤波、目标限幅、PWM 换算及启停 |
| [servo_config.h](Application/Inc/servo_config.h) | PWM 量程、逐轴限位、ADC 标定和外环参数 |
| [uart_io.c](Application/Src/uart_io.c) / [arm_protocol.c](Application/Src/arm_protocol.c) | USART1 中断收发；主循环解帧、执行命令并应答 |

- TIM1/TIM2 输出 **50 Hz** PWM，计数频率 **3 MHz**。`0–270°` 线性映射到 **500–2500 μs**，`135°` 对应 `1500 μs`。
- SWD 调试：`target_deg` 是设定目标，`command_deg` 是实际 PWM 指令角，`feedback_deg` 是换算并滤波后的反馈角，`feedback_adc` 是原始采样，`pwm_ticks` 是 CCR 计数。

## 限幅与失能

| 轴 | 舵机命令角 |
|---|---|
| J1 底座 | `0–270°` |
| J2 肩 | `100–216°` |
| J3 肘 | `50–260°` |
| J4 腕俯仰 | `83–230°` |
| J5 腕滚转 | `0–270°` |
| J6 夹爪 | `60–133°` |
| J7 备用 | `0–270°` |

- 限位用舵机命令角。在固件改 `SERVO_Jx_OUTPUT_LIMITS` 时，同步更新网页 [commandLimits](../WebHost/model.json) 中的在用轴。串口指令中任何选中轴越界，整帧拒绝；本地舵机 API 将输出限制在该轴范围内。
- ADC 外环默认关闭，PWM 指令跟随目标。启用外环后，修正量限制在目标的 `±15°` 内，最终仍受逐轴限位约束。
- ADC 两点标定用 `SERVO_ADC_CALIBRATION(舵机角A, ADC_A, 舵机角B, ADC_B)`。两点 ADC 必须不同，斜率由原始配对决定。当前未填两点数据的轴按配置方向估算反馈角。
- 上电默认不发 PWM。失能时清零 PWM 输出并保留目标角；它只停止控制信号，舵机仍通电。断开串口会保留板端的目标和 PWM 使能状态。

## USART1 协议 V2

H9 接 USART1：1 脚 GND、3 脚 TX（PB6）、4 脚 RX（PB7）。串口为 **115200 / 8N1，无流控**。板载 USB CDC 保留为独立接口。

| 偏移 | 字节数 | 字段 |
|---|---:|---|
| 0 | 2 | 同步字 `AA 55` |
| 2 | 1 | 版本 `02` |
| 3 | 1 | 消息类型 |
| 4 | 2 | 请求序号 `seq`，应答原样返回 |
| 6 | 2 | 载荷长度 `len`，范围 `0–512` |
| 8 | `len` | 载荷 |
| `8 + len` | 2 | CRC，覆盖版本字节至载荷末尾 |

多字节整数均为小端序，最大帧长 522 字节。CRC 使用 CRC-16/CCITT-FALSE：多项式 `0x1021`、初值 `0xFFFF`、不反射、结果异或 `0x0000`。测试字符串 `123456789` 的校验值为 `0x29B1`，线上为 `B1 29`。

| 请求 | 载荷 | 应答 |
|---|---|---|
| `0x01 SET_TARGETS` | `mask:u8 + 6 × angle:u16`，13 字节；只更新选中轴 | `0x80 ACK` |
| `0x02 SET_ENABLE` | `mask:u8 + enable:u8`，`0` 关闭 PWM，`1` 使能 | `0x80 ACK` |
| `0x03 READ_FEEDBACK` | 无 | `0x81 FEEDBACK` |
| `0x04 PING` | 任意 `0–512` 字节 | `0x84 PONG`，原样返回载荷 |

- **轴序与角度**：掩码低 6 位对应 J1～J6，数组也按该顺序排列。掩码不能为 0，J7 不参与。角度为无符号舵机角，单位 `0.01°`，如 `133°` 编码为 `13300`。
- **ACK**：`请求类型:u8 + 状态:u8`。状态 `0` 已处理、`1` 长度错误、`2` 参数无效或越界、`3` 未知命令。ACK 不表示到位。
- **FEEDBACK**：共 38 字节。先发 `使能掩码:u8 + 已采样掩码:u8`，再按轴重复 `目标角:u16 + 反馈角:u16 + ADC 原始值:u16`。已采样位表示该轴曾获得有效 ADC 样本。
- **解析与应答**：支持分段接收，每轮最多处理 128 字节。半帧空闲超过 100 ms 会丢弃；CRC 或版本错误不应答。发送忙时留待下一轮。网页按 `seq` 匹配应答，一次只等待一个请求。
